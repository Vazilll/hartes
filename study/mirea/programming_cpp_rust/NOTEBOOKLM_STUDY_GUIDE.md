## ❓ 2. Grounded Q&A & Exam Tickets (Билеты с Ссылками на Первоисточник)

### 📌 Билет №1: Управление памятью в C++ и Rust
* **Вопрос:** В чём отличие между выбором стека (`Stack`) и кучи (`Heap`) для хранения локальных структур данных?
* **Заземлённый Ответ [Методичка МИРЭА, Раздел 2.1, стр. 14]:**
  * *Стек*: Переменные выделяются со сдвигом указателя стека (`RSP`), время выделения $\mathcal{O}(1)$. Автоматическое освобождение при `RET`.
  * *Куча*: Память запрашивается у ОС через `sys_brk`/`mmap`. Время выделения зависит от аллокатора. В C++ замена ручного `delete` производится деструктором `std::unique_ptr` (RAII). В Rust правка гарантируется `Borrow Checker` [стр. 18].
* **Цитата из источника:** *«Использование сырых указателей в куче без RAII является причиной 70% ошибок утечки памяти (Memory Leaks)»*.
