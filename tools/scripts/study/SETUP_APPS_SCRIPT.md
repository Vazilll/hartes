# 🧠 DNTS Brain — Установка Google Apps Script

Инструкция по настройке автоматической генерации `brain_state.md`.

---

## Предварительные требования

- Google-аккаунт
- API-ключ Gemini (получить на [aistudio.google.com](https://aistudio.google.com/apikey))
- Структура папок на Google Drive:
  ```
  Google Drive/
  └── ai/
      └── dialogues cli/
          ├── dialogue_001.md
          ├── dialogue_002.md
          └── ...
  ```

---

## Шаг 1. Создание проекта

1. Откройте [script.google.com](https://script.google.com)
2. Нажмите **«Новый проект»** (или «+ New project»)
3. Дайте проекту имя: `DNTS Brain`

---

## Шаг 2. Вставка кода

1. Удалите содержимое файла `Code.gs` (он создаётся по умолчанию)
2. Скопируйте **весь** код из файла `google_apps_script.js`
3. Вставьте его в `Code.gs`
4. Сохраните (`Ctrl+S`)

---

## Шаг 3. Настройка API-ключа

> [!IMPORTANT]
> API-ключ **НИКОГДА** не должен быть захардкожен в коде. Используйте Script Properties.

1. Откройте **Project Settings** (⚙️ иконка шестерёнки слева)
2. Прокрутите вниз до раздела **«Script Properties»**
3. Нажмите **«Add script property»**
4. Заполните:
   - **Property**: `GEMINI_API_KEY`
   - **Value**: ваш API-ключ (например, `AIzaSy...`)
5. Нажмите **«Save script properties»**

---

## Шаг 4. Первый тестовый запуск

1. Вернитесь в редактор кода
2. В выпадающем списке функций выберите `testSetup`
3. Нажмите ▶ **«Run»**
4. При первом запуске появится окно авторизации:
   - Нажмите **«Review permissions»**
   - Выберите свой Google-аккаунт
   - Нажмите **«Advanced»** → **«Go to DNTS Brain (unsafe)»**
   - Нажмите **«Allow»** (разрешить доступ к Google Drive и Sheets)
5. Проверьте логи: **View → Logs** (или `Ctrl+Enter`)
6. Все пункты должны быть ✔

### Тест Gemini API

1. Выберите функцию `testGeminiApi`
2. Нажмите ▶ **«Run»**
3. В логах должен появиться ответ от Gemini

### Полный тестовый запуск

1. Выберите функцию `generateBrainState`
2. Нажмите ▶ **«Run»**
3. Проверьте, что в папке `ai/` появились файлы:
   - `brain_state.md` — сгенерированный отчёт
   - `sync.log` — журнал синхронизации

---

## Шаг 5. Настройка автоматического триггера

Скрипт должен запускаться автоматически каждые 6 часов.

1. Откройте **Triggers** (⏰ иконка будильника слева)
2. Нажмите **«+ Add Trigger»** (внизу справа)
3. Настройте:

| Параметр | Значение |
|----------|----------|
| Choose which function to run | `generateBrainState` |
| Choose which deployment should run | `Head` |
| Select event source | `Time-driven` |
| Select type of time based trigger | `Hours timer` |
| Select hour interval | `Every 6 hours` |
| Failure notification settings | `Notify me daily` |

4. Нажмите **«Save»**

---

## Шаг 6. Настройка таблицы заметок (опционально)

Поскольку Google Apps Script не имеет прямого доступа к Google Keep,
заметки читаются из Google Sheet.

1. Создайте таблицу на Google Drive с именем **`DNTS Notes`**
2. На первом листе создайте заголовки:

| Дата | Тег | Заметка | Статус |
|------|-----|---------|--------|
| 2026-06-21 | #dnts | Пример заметки | todo |
| 2026-06-20 | #dnts | Ещё одна | in progress |

3. Заполняйте заметки с тегом `#dnts`
4. Скрипт автоматически прочитает их при следующем запуске

---

## Шаг 7. Файл USER.md (опционально)

Если хотите кастомизировать профиль:

1. Создайте файл `USER.md` где угодно на Google Drive
2. Напишите в нём информацию о себе в формате Markdown
3. Скрипт найдёт его автоматически при следующем запуске

Если `USER.md` не найден, используется встроенный профиль по умолчанию.

---

## Структура выходного файла

Сгенерированный `brain_state.md` содержит:

```
# 🧠 DNTS Brain State
> Сгенерировано автоматически: 21 июня 2026, 17:00

## 👤 Профиль
  (из USER.md или встроенный)

## 📋 Активные задачи
  (задачи со статусом todo/in progress из DNTS Notes)

## 💬 Последние диалоги
  (саммари последних 5 диалогов через Gemini)

## 📝 Быстрые заметки
  (все #dnts заметки из DNTS Notes)

## ⚙️ Статус системы
  (метаданные синхронизации)
```

## Устранение неполадок

### «Папка "ai" не найдена»
Создайте папку `ai` в корне Google Drive (не внутри другой папки).

### «GEMINI_API_KEY не задан»
Убедитесь, что добавили ключ в Script Properties (Шаг 3).

### «Ошибка Gemini API 429»
Превышен лимит запросов. Скрипт уже включает задержку 1 сек между запросами.
Если ошибка повторяется — увеличьте интервал триггера.

### «Нет доступа к файлу»
Запустите `testSetup` — при первом запуске система запросит авторизацию
на доступ к Google Drive и Google Sheets.

### Логи выполнения
- **Apps Script логи:** View → Logs (`Ctrl+Enter`)
- **Executions:** View → Executions (история всех запусков)
- **sync.log:** Файл в папке `ai/` на Google Drive

## Лимиты Google Apps Script

| Ресурс | Лимит (бесплатный аккаунт) |
|--------|---------------------------|
| Время выполнения скрипта | 6 минут |
| Вызовов UrlFetch в день | 20 000 |
| Триггеров на проект | 20 |
| Объём Drive операций | 250 МБ / запуск |

При нормальной работе (5 диалогов × 1 запрос Gemini) скрипт укладывается
в ~30 секунд и использует 5-10 вызовов API.
