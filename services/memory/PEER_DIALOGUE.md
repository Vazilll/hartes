## 2. Разбор 4 векторов оптимизации (Adversarial Review)

### Вектор 1: Confused Deputy & Task-Scoped Capability Tokens
* **Предложение**: Non-Human Identity, временные capability-токены с ограничением скоупа.
* **Критика**: Реализация через `system_personas.py` (текстовые промпты) бесполезна против инъекций.
* **Решение**: Фильтрация строго в `pre_tool_hook.py` по белому списку директорий `C:\vazus` и scratch-папки (Fail-Closed). Никакой лишней криптографии — чистый Path Jail на уровне ОС.

### Вектор 2: Спекулятивное выполнение тулов (Speculative Pre-fetching)
* **Предложение**: NPU на Intel AI Boost параллельно префетчит `git status`, diff, факты памяти.
* **Критика**: Опасность гонок и сайд-эффектов при префетче мутирующих тулов.
* **Решение**: Жесткий `Idempotency Guard` (только read-only: `view_file`, `git status`, `sqlite-select`). В качестве предиктора — сверхбыстрый `ModernBERT/Verdict` (<10 мс).

### Вектор 3: Stateless MCP на Google Cloud Run
* **Предложение**: Миграция на Stateless Header-Routed HTTP (спецификация 2026-07-28), Scale-to-Zero.
* **Критика**: Оверинжиниринг для локальной машины. При Scale-to-Zero теряется контекст между репликами.
* **Решение**: Заворачивать сессионный контекст в подписанный заголовок `X-Agent-State`. Использовать только для мобильного доступа (Gemini Spark), локально подключаться напрямую через Stdio/IPC.

### Вектор 4: Адаптивное перевзвешивание J-Space
* **Предложение**: Формула $W = W \times (1 + (\text{Used}/\text{Proposed} - 0.5) \times \alpha)$.
* **Критика**: Проблема холодного старта — редкие, но критические тулы (SMT Z3, Rollback) вымоются в 0.
* **Решение**: Добавить UCB1-исследовательский бонус и нижнюю отсечку $\text{clamp}(W, 0.25, 2.5)$.
