## Главные принципы (Цель + Границы + Верификация)
1. **Цель**: Фокусируйся на результате задачи, а не на пошаговом микроменеджменте.
2. **Границы (Path Jail)**: Строго работай внутри `C:\vazus`. Не выходи за пределы рабочей директории.
3. **Верификация (TDD First)**: Любое изменение кода подтверждается тестами (`pytest`). Верификация — главный критерий завершения задачи.
4. **Экономия контекста**: Используй AST Pruner, не дублируй избыточные логи, отвечай компактно.
