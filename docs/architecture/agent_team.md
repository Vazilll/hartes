# Agent Team: параллельные агенты в Antigravity

Источники: видео про RLM (context rot) и G3 (Player-Coach), NotebookLM `8623fd10-c712-4698-9006-c2b29a43441a` (40 найденных источников), пилот `adversary_reviewer` от 2026-10-03.

## Ограничения платформы (проверено по `hooks.md`)
- Хуки только `type: command`, синхронные, без состояния между вызовами. Состояние хранится только в файлах.
- Блокировка: `PreToolUse` возвращает `decision: deny`; `Stop` возвращает `decision: continue`.
- Субагенты запускаются через `invoke_subagent` (параметр `Model`: `flash`/`pro`), общаются через `send_message`.
- НЕ проверено: есть ли в payload хука идентификатор агента (аналог `agent_type`) и поле `stop_hook_active`. Пока не проверено, защита от зацикливания строится на собственном счётчике в файле.

## Роли
| Роль | Права | Модель | Статус |
|---|---|---|---|
| Главный агент (писатель + агрегатор) | единственный пишет в проект | основная | есть |
| Критик (`adversary_reviewer`) | read-only + ruff/ast/pytest, запись только в `logs/review/` | flash | пилот пройден |
| Исследователь кода | read-only (view/grep/cbm) | flash | не создан |
| Веб-исследователь | web + NotebookLM | flash | не создан |

Принцип G3: критик не пишет код. Принцип RLM: тяжёлые данные остаются вне контекста главного агента, а он получает короткие сводки.

## Потоки данных (файлы)
- `logs/review_feed.jsonl` — PostToolUse дописывает каждую правку (файл, инструмент, время).
- `logs/review/review_verdict.json` — вердикт критика: `{open_objections:[...], round, ts}`.
- `logs/research/<topic>.md` — отчёты исследователей (сводка 1-2 абзаца, полный след не возвращается в контекст).

## Формат возражения критика
- `AGREE`
- `DISAGREE_EVIDENCE: <file:line + команда + вывод>` — блокирует остановку
- `DISAGREE_CONCERN: <причина>` — главный агент подтверждает или опровергает кодом, не блокирует

## Критерии остановки и защита
1. `Stop`-хук читает `review_verdict.json`; есть `DISAGREE_EVIDENCE` → `continue` с причиной.
2. Не больше 2 блокировок на сессию (счётчик в `logs/review/rounds.json`). После лимита остановка разрешена, вердикт показывается пользователю.
3. Возражение без воспроизводимого доказательства не блокирует.
4. Таймаут критика → fail-open (остановка разрешена).
5. Критик работает на flash; исследователи запускаются только по явной задаче.
6. Педагогический суверенитет: агенты не решают учебные задания (`USER.md`).
