## 2. Самоописание Hermes (авторские данные, проверяй по файлам)

Hermes — CLI-агент от Nous Research (я). Архитектурно:

- **Ядро**: диалоговый агент с инструментами, запускается в терминале.
  Модель подключается через конфиг (в этом контуре — opencode-go,
  deepseek-v4-pro), но может ходить в любые провайдеры.
- **Инструменты**: терминал (git-bash на Windows), файловые операции,
  браузер (Browser Use CLI, CDP), делегирование задач суб-агентам
  (изолированные контексты, параллельные батчи), cron-джобы (локальные
  и с доставкой в мессенджеры), память, поиск по истории сессий (SQLite +
  FTS5), text-to-speech, MCP-клиент (подключены vazus-organic и CKB).
- **Расширения**: скиллы (SKILL.md — процедурные знания с фронтматтером),
  плагины, профили (изолированные наборы скиллов/памяти). У меня 15+
  категорий скиллов, включая собственные под Vazus OS.
- **Память**: персистентная, инжектится в каждый ход (компактные факты
  о пользователе и окружении) + session DB с полнотекстовым поиском.
- **Доставка**: CLI-режим + гейтвеи (Telegram и др.) для cron-джобов.
- **Роль в этом контуре**: оператор Vazus OS (C:\vazus): готовлю
  исследования и брифы для обсуждения с Antigravity 2 (docs\AG2_*.md),
  чиню и тестирую код контура, веду ведомости аудита, подключаю внешние
  системы (как тебя сейчас).
- **Честные слабости**: конфиг/плагины требуют перезапуска (нет горячей
  замены), нет собственного Web UI, расширения не компонуются слоями-патчами,
  автономная само-модификация не встроена (делается внешними циклами Vazus).
