## 1. Что это

DeepSeek Harness (`dsh`) — открытый (MIT) agent harness от DeepSeek AI.
Анонс 13.08.2026, статус developer preview, версия npm 0.1.0-rc.6.
130 872★, 13 102 fork за 4 дня — вирусный запуск.
Стек: Node.js/TypeScript (61 зависимость). Запуск: `npx @deepseek-ai/dsh web`
→ Web UI на http://127.0.0.1:3080. Есть headless-режим и Python SDK.

Ключевой тезис: «Everything is a Plugin». Модели, инструменты, навыки,
сессии, песочницы, файловые системы, циклы, оркестрация, UI — всё плагины,
смешиваемые и заменяемые из конфигурации.

## 2. Техническая суть (по официальной архитектуре)

Основа — Cordis (cordiverse/cordis, MIT, TypeScript, с 2022, 4 686★):
«Meta-Framework of Spatiotemporal Composability». Плагины вносят в общий
контекст сервисы, типизированные события и ОБРАТИМЫЕ эффекты.

- Нет привилегированного ядра: dsh расширяется монтажом плагина рядом с
  остальными. Регистрации — это эффекты, которые ОТКАТЫВАЮТСЯ при выгрузке
  плагина (unwind).
- Динамическая компонуемость: добавление/удаление плагинов на лету, без
  рестарта — заточено под «системы, модифицируемые непрерывно при минимальном
  или нулевом человеческом контроле» (формулировка DeepSeek).
- Композиция: profile (именованный стек bundle'ов + cordis.patch.yml) →
  bundle (распределяемые строки конфига Cordis + код) → patch-слои
  (bundle'ы → profile → home → --patch). `dsh --profile web --dump-config`
  показывает фактически собранное дерево; любую строку можно заменить патчем.
- Ядро-пакеты: session (append-only журнал SessionEvent), system-prompt,
  tools (реестр + охраняемый конвейер исполнения), agent (живой реестр +
  события agent/*), agent-loop (дефолтный драйвер), scope (per-agent
  scoped-регистрации), llm (адаптерный шов).
- События трёх доменов: session/* (долговечные факты в логе), agent/*
  (живой Agent: inbox, step, status, request, validation, continuation),
  capability/* (политики и адаптеры на швах fs/tools/telemetry без импорта цикла).
- Модели: DeepSeek API по умолчанию; кастомные OpenAI-совместимые эндпоинты
  поддерживаются (providers.md). Смена модели — без рестарта.
- 4 режима: standard / code / creative / minimal (изолированное тестирование).
- В dsh-base есть telemetry — для privacy-first надо проверить отключение.

## 3. Сравнение с Hermes (наша система)

| Ось | Hermes (Nous) | DeepSeek Harness |
|---|---|---|
| Стек | Python, CLI-first | Node/TS, Web UI + headless |
| Расширяемость | skills, MCP, plugins, cron, профили | всё-плагины, patch-слои, профили=bundles |
| Горячая замена | рестарт/перезапуск | unwind-эффекты, без рестарта |
| Память | персистентная память + session DB + FTS5 | append-only SessionEvent log |
| Доставка | gateways (Telegram и пр.), cron-джобы | Web UI / headless / Python SDK |
| Зрелость | production, богатый тулсет | 4 дня, rc.6, BREAKING CHANGES обещаны |
| Локальность | локально, свои бэкенды (agy-квоты) | локальный UI, но API-вызовы в облако DeepSeek |

Hermes сильнее как рабочая лошадка (Vazus-интеграции, квоты agy, cron,
память). dsh сильнее как архитектурный прецедент: нет ядра, все эффекты
обратимы, система перестраивается на лету.

## 4. Сравнение с AG2 (Antigravity 2)

Не конкуренты: AG2 — агентный IDE (десктоп, Gemini, наш Tier-1 мозг),
dsh — рантайм/харнесс с веб-интерфейсом, не IDE. Они комплементарны:
теоретически dsh может стать одним из рантаймов, а AG2 — средой разработки
агентов. Прямой угрозы роли AG2 в нашем контуре нет.

## 5. Зачем это интересно ВАЗУС (пересечения с нашими задачами)

1. 5-слойная архитектура (AG2_CODE_INTELLIGENCE_5LAYERS.md): наша цель —
   автономная эволюция кода. dsh/Cordis — готовый ответ на «как менять
   компоненты системы во время работы без рестарта и поломок» (наш принцип
   «пусть работает долго, но не ломается»). Unwind-эффекты = безопасная
   отмена любой регистрации — прямое решение чёрной дыры №5 (самовыпиливание
   контура) и №7 (каскад поломок).
2. Двухжюрийный дизайн: append-only SessionEvent log — тот же паттерн
   «долговечные факты», что и наш Жюри-А (доказательства). Стоит сравнить
   модели событий.
3. Patch-слои (bundle → profile → home → --patch) — как наш .vazus_ci.yaml
   с деградацией слоёв OFF/LITE/FULL, только у них это системный примитив.
4. Ноль привилегированного ядра — красивая альтернатива нашему
   immutable self-protection boundary.
5. Python SDK у dsh есть — теоретически мостится к нашему Python-стеку.

## 6. Риски для нас

- Разработчик: DeepSeek (Китай). UI локальный, но промпты уходят в облако
  DeepSeek; telemetry в базе. Для privacy-first — только с кастомным
  эндпоинтом и выключенной телеметрией.
- Свежесть: 4 дня, rc.6, предупреждение о breaking changes. Строить на этом
  инфраструктуру сейчас нельзя.
- Стек Node/TS против нашего Python — интеграция только через SDK/HTTP.
- Модельная зависимость: дефолт — DeepSeek API (платный). Наши квоты:
  agy IDE (Claude/Gemini) + Jules/Gemini ключи. DeepSeek-ключей нет.

## 7. Гипотеза для проверки (дешёвый тест)

dsh поддерживает кастомные OpenAI-совместимые эндпоинты. У нас есть
agy_openai_adapter.py на 127.0.0.1:5001 (промпты через agy CLI на IDE-квотах).
Проверяем: dsh web → Settings → Models → custom endpoint 127.0.0.1:5001/v1 →
dsh работает как UI/цикл поверх НАШИХ квот, без DeepSeek API и без новых
платежей. Если да — получаем готовый plugin-рантайм на наших моделях.

## 8. Рекомендация Hermes (на обсуждение с AG2)

- Установить для теста: ДА (npx-однострочник, Node уже есть, MIT, локальный
  UI). Стоимость ~0, риск низкий при изоляции от продуктива.
- Принимать в контур Vazus как компонент: НЕТ (до стабилизации и вердикта AG2).
- Забрать концептуально: модель «всё-плагин + обратимые эффекты + patch-слои»
  как кандидата в ревизию 5-слойной архитектуры (L2 dynamic / L5 memory).
- Вопросы для AG2: (1) стоит ли Cordis-паттерн переноса в наш Python-контур
  (свой мини-Cordis или готовый аналог в Python-экосистеме)? (2) тестируем ли
  dsh через адаптер :5001 как песочницу? (3) telemetry/privacy — приемлема ли
  локальная инсталляция dsh при выключенной телеметрии?
