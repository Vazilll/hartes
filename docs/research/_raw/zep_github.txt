It contains example code, framework integrations, and tools for building agent memory with Zep Cloud , Zep's managed agent memory platform. To use Zep Cloud, sign up at www.getzep.com and read the documentation at help.getzep.com . Zep's official SDKs are: Python : pip install zep-cloud TypeScript/JavaScript : npm install @getzep/zep-cloud Go : go get github.com/getzep/zep-go/v3 Looking for the open-source temporal knowledge graph framework that powers Zep? See Graphiti .
