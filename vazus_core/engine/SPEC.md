## 1. Core Mission & Domain Scope (Responsibilities & Boundaries)
### 1.1 Primary Mission
The `engine` component operates as the central reasoning, execution, and verification backbone of Vazus SuperGraph OS. It provides AST code topology mapping, dynamic skill dispatching, subagent lifecycle orchestration, SMT Z3 formal logic verification, Concordia multi-agent jury consensus arbitration, and self-healing compilation loops.

### 1.2 Strict Boundary Rules
- **ALLOWED**:
  - Deterministic execution of AST-verified symbols and local REPL sandboxes.
  - Dynamic skill matching and intent parsing via DynamicSkillDispatcher.
  - SMT Z3 contract proof validation and Concordia jury consensus voting (>= 66%).
  - AST signature pruning achieving token economy and repo map generation.
- **PROHIBITED**:
  - Unsandboxed arbitrary shell or code execution escaping workspace boundaries.
  - Unauthorized external billing API imports and external token budget leaks.
  - Infinite retry loops or unbounded recursion in self-healing compiler loops.
  - Blocking main event loop with heavy CPU-bound graph analysis.

### 2.4 Invariant Guarantees & Safety Policies (Invariants & Safety Guarantees)
- Invariant 1: Formal verification guarantees UNSAT contract proofs before code promotion.
- Invariant 2: Dynamic skill dispatch enforces sub-50ms intent matching and sandbox bypass rules.
- Invariant 3: Multi-agent consensus requires at least 66% affirmative votes to commit code changes.

## 3. Progressive Skill Level (Level 1..5 Capability Maturity) & Upgrade Criteria
- **Level 1 (Basic Execution Runtime)**: Single-turn execution, baseline AST parsing, and standalone REPL execution.  
  *Upgrade criteria*: Add structured error handling and unit test coverage.
- **Level 2 (Resilient Subagent Pipeline)**: Multi-step subagent execution with circuit breakers and timeout governors.  
  *Upgrade criteria*: Integrate typed contracts and SQLite WAL logging.
- **Level 3 (Integrated SuperGraph & SMT)**: Full integration with AST repo mapping, SMT Z3 verification, and Concordia jury.  
  *Upgrade criteria*: Add autonomous self-healing compiler and memory feedback loops.
- **Level 4 (Autonomous Self-Healing Loop)**: Closed-loop failure diagnosis, AST pruning, and Reflexion memory integration.  
  *Upgrade criteria*: Support distributed execution and NPU hardware acceleration.
- **Level 5 (Self-Sustaining Cognitive Governor)**: Zero manual intervention, autonomous task routing, and verified invariant stability.

## 4. Known Bottlenecks & Failure Modes (Optimization Backlog)
- [ ] Subprocess latency during recursive self-healing compiler invocations under heavy load.
- [ ] AST parsing overhead on deeply nested multi-thousand LOC modules.
- [ ] Rate limiting on external LLM calls during dialectical synthesis.
