## 1. Core Mission & Domain Scope (Responsibilities & Boundaries)
### 1.1 Primary Mission
The `memory` component provides persistent multi-tiered memory governance, Mem0 episodic fact storage, SQLite WAL pooling, 768-D vector embeddings (UnifiedGoogleEmbedder and OpenVINO NPU), and biological sleep-time dream consolidation within Vazus SuperGraph OS.

### 1.2 Strict Boundary Rules
- **ALLOWED**:
  - Thread-safe SQLite WAL queries, transactions, and connection pooling via AsyncDatabasePool.
  - Bitemporal fact updates and 768-D cosine similarity indexing with SIMD/AVX-512 acceleration.
  - Memory tier promotion from UNTRUSTED_OBSERVATION to VERIFIED_FACT.
  - Dream consolidation, reflexion lesson storage, and Karpathy markdown wiki synchronization.
- **PROHIBITED**:
  - Writing unverified user preferences or mutating facts without explicit instruction.
  - Unbounded database growth exceeding statutory 25.0 MB invariant limit.
  - Naked SQLite connections bypassing shared connection proxy or WAL mode.
  - Storing unindexed raw embeddings outside vector index tables.

### 2.4 Invariant Guarantees & Safety Policies (Invariants & Safety Guarantees)
- Invariant 1: All SQLite operations enforce WAL journal mode with exponential retry backoffs.
- Invariant 2: Database file size is strictly capped <= 25.0 MB via automated VACUUM and pruning.
- Invariant 3: 768-dimensional embeddings maintain L2 normalization for exact cosine indexing.

## 3. Progressive Skill Level (Level 1..5 Capability Maturity) & Upgrade Criteria
- **Level 1 (Direct File Storage)**: File-based JSON and markdown note storage with synchronous file writes.  
  *Upgrade criteria*: Migrate storage to SQLite with WAL mode.
- **Level 2 (Transactional SQLite WAL)**: Shared connection pooling, thread safety, and structured fact tables.  
  *Upgrade criteria*: Add vector embeddings and semantic similarity search.
- **Level 3 (Multi-Tiered Vector Store)**: 768-D vector embeddings, AVX-512 SIMD search, and Mem0 episodic fact management.  
  *Upgrade criteria*: Implement sleep-time dream consolidation and reflexion lessons.
- **Level 4 (Dream Consolidation & Self-Healing)**: Asynchronous consolidation of lessons, bitemporal fact reconciliation, and wiki graph linking.  
  *Upgrade criteria*: Support NPU on-device embedding acceleration.
- **Level 5 (Self-Sustaining Knowledge Organism)**: Fully closed memory loops, autonomous dream compaction, zero dangling edges, and proactive context injection.

## 4. Known Bottlenecks & Failure Modes (Optimization Backlog)
- [ ] SQLite WAL checkpoint contention during high-frequency concurrent subagent flushes.
- [ ] 768-D embedding inference latency when falling back from NPU to CPU.
- [ ] Graph edge orphan accumulation in kg_edges before dream consolidator prune runs.
