# Параллельные агенты и хуки (Antigravity)

- Хуки Antigravity: только `type: command`, синхронные, без состояния между вызовами. Состояние лежит в файлах (`logs/`) или в `vazus.db`.
- Хук не загружает тяжёлые модели (TimesFM, веса LLM) в свой процесс. Тяжёлое делает резидентный процесс, а хук обращается к нему с таймаутом и имеет быстрый фолбэк.
- Критик (`adversary_reviewer`) только читает и проверяет. Возражение считается блокирующим, только если приложены команда и вывод. Не больше 2 блокировок остановки на сессию, при таймауте критик пропускается.
- Исследователи (`code_researcher`, `web_researcher`) только читают и возвращают сводку из нескольких абзацев, без полных файлов.
- Новый код хуков не считается готовым, пока не прогнан на реальном payload и не проверен результат в логе или БД.
- Агенты не решают учебные задания пользователя (педагогический суверенитет, `USER.md`).
