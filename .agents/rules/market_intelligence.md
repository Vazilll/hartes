# Market Intelligence & Empirical Consensus Invariants

## 1. Rank-Biased Overlap (RBO) over Edit Distance
- При анализе динамики спроса, списков заказов и рейтингов технологий использовать Rank-Biased Overlap (RBO) с параметром $p=0.85$ вместо обычного расстояния Левенштейна. Топ-10 позиций несут 86% веса рыночной значимости.

## 2. Multi-Signal Intent Disambiguation
- Запрещено определять тип задачи (заказ, научный запрос) исключительно по косинусному сходству векторов эмбеддингов.
- Использовать трёхсигнальную триангуляцию:
  1. Лексические триггеры интента (Transactional, Commercial, Informational, Spam).
  2. Графовое пересечение стеков (Jaccard Adjacency $\ge 0.30$) с выделением стержневого заказа (Pillar Order).
  3. Проверка профиля риска (Zero-Trust к сомнительным внешним контактам и бесплатным тестовым).

## 3. Search Grounding Deduplication (Orthogonality Gate)
- В глубоких поисковых исследованиях (`open_deep_research`) перед загрузкой веб-страниц обязательно вычислять коэффициент пересечения URL из `grounding_chunks`. При дублировании свыше 50% запрос отсекается для экономии токенов и устранения информационного шума.

## 4. Academic Knowledge Gap Engine
- Анализ задолженностей студента (РТУ МИРЭА) производить через вычисление разности множеств требуемых и освоенных концептов:
  $$\text{Gap}(S) = G_{\text{curriculum}}(S) \setminus G_{\text{mastered}}(S)$$
- Для выбора следующей темы для Сократического диалога ранжировать понятия по степени связности (out-degree centrality) в графе пререквизитов `kg_edges` (`prerequisite_for`), чтобы закрывать базовые понятия, открывающие максимум экзаменационных вопросов.
