## 2024-10-24 - Pure Python Vector Math Optimization
**Learning:** The codebase intentionally avoids external dependencies like NumPy for tasks such as FTS embedding matching in `preflight_filter.py`. While pure Python math is slower, significant speedups (e.g., 3x reduction in execution time) can still be achieved without sacrificing readability by leveraging C-implemented built-ins: replacing generator expressions and `zip` with `sum(map(operator.mul, ...))` for dot products, and replacing manual sum-of-squares with `math.sqrt(sum(map(operator.mul, ...)))` for L2 norms.
**Action:** When working on math-heavy pure Python loops in this project, proactively scan for opportunities to push iterations down to the C layer using `map`, `operator`, and specialized `math` functions instead of suggesting NumPy, which would violate architectural constraints.
